Choose the route deliberately

PHNX supports direct connections and configured HTTP, HTTPS, SOCKS4, and SOCKS5 behavior where the device runtime allows it. Public proxy routes are visible choices with explicit limitations.

Key points

  • Proxy settings are profile-aware.
  • Public proxies may inspect or modify traffic and are not anonymity tools.
  • Do not use public proxy routes for passwords, payments, or confidential data.
