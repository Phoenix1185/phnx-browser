Features

Control the browser surface.

PHNX is built around practical Android browsing: profiles, permissions, network choices, resource management, and clear safety boundaries.

Chromium browsing

Fast modern web browsing powered by the Android System WebView runtime. The installed WebView provider determines the exact Chromium version.

Implemented
Profiles

Profiles separate supported cookies, storage, permissions, history, sessions, identity settings, and network configuration.

Implemented
Network and proxy

Choose a direct route or configure HTTP, HTTPS, SOCKS4, or SOCKS5 behavior where the device runtime supports it.

Implemented
Privacy and security

JavaScript, cookies, pop-ups, Safe Browsing, site permissions, HTTPS state, download checks, and clear-data controls.

Implemented
Ad and tracker blocking

Profile-aware local blocking with site exceptions and request statistics. Blocking is not a promise that every ad or tracker is stopped.

Implemented
Performance

Resource policy coordinates profile and WebView lifecycle states to keep multiple browsing contexts manageable.

Implemented
Browser features

Downloads, bookmarks, history, private tabs, find-in-page, zoom, full-screen, file selection, and external-link intents.

Implemented
Self-updates

Typed manifests, checksum/signature primitives, and release discovery are present. Production artifact delivery is still unfinished.

In progress
Default browser

Android browser-role controls and HTTP/HTTPS intents respect Android system choice and user consent.

Implemented
Boundaries

Useful controls,
not magic claims.

  • PHNX does not claim complete anonymity or total protection from tracking.
  • Private tabs do not create a separate WebView cookie partition.
  • Public proxies are third-party routes and are not suitable for passwords or payments.
  • Website permissions remain separate from Android runtime permissions.
