Privacy

Protection and limits, clearly stated.

Local by design. PHNX stores its browser data in the Android app and WebView profile directories. It does not operate an analytics or advertising service in this build.

Profiles are meaningful, not magic. Profile storage, history, bookmarks, permissions, identity settings, and network settings are scoped where Android WebView allows it. Private tabs provide session and history hygiene, not a separate WebView cookie partition.

Routes are visible. Public proxies are third-party routes that may inspect or modify traffic. They are not anonymity tools and must not be used for passwords, payments, or confidential data.

Security

Safe defaults.
Honest boundaries.

Navigation safety. HTTPS state, certificate errors, Android Safe Browsing, download risk checks, dangerous-download confirmation, and mixed-content controls are surfaced or enforced where supported.

Release safety. Update manifests have typed validation, SHA-256 verification, ECDSA signature verification primitives, and guarded state transitions. Production signing keys, atomic installation, rollback, and release infrastructure are not yet configured.

Permission safety. Website camera, microphone, and location requests are separate from Android runtime permissions and require explicit user decisions.

About PHNX

Built in public.
Built by Phoenix.

PHNX Browser is a fast, private, and powerful Android browser built for modern browsing. Built & engineered by Phoenix, PHNX focuses on performance, privacy, profile isolation, resource management, and a clean modern browsing experience.

Current engine: Android System WebView, using the device’s Chromium-backed runtime. The exact Chromium version depends on the installed WebView provider.

© 2026 Phoenix. The project is open in its repository, with licenses, terms, privacy behavior, and implementation limitations kept visible.
